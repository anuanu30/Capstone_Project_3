# Error Analysis Report

## Overview

This report examines false positives and false negatives generated by the churn prediction model.

False negatives are considered more costly because they represent customers who churned without being identified.

---

## False Positives

Definition:
Customers predicted to churn who actually remained active.

Business Risks:

* Unnecessary retention spending
* Excessive discount allocation
* Wasted marketing budget

## Recommendations

1. Add sentiment-based features.
2. Create a dedicated model for new customers.
3. Monitor false negatives closely.
4. Retrain periodically to reduce model drift.
